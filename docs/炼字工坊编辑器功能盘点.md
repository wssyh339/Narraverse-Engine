## 2. 产品整体结构

该页面不是单一正文编辑器，而是一套覆盖小说立项、作品资料、设定管理、大纲管理、正文写作、AI 辅助、版本恢复和发布的创作工作台。

页面由以下区域组成：

1. 顶部全局工具栏：作品切换、工作区切换、同步、主题、灵感、设置、历史和灵石。
2. 左侧固定章节目录：分卷、章节、字数、批量操作、排序、回收站、导出和发布。
3. 中央主工作区：随“作品 / 目录 / 设定 / 大纲 / 笔记”切换。
4. 右侧 AI 助手区：小说全能助手、快捷任务、上下文关联、引用、模型和对话输入。
5. 正文辅助浮动工具：炼字大师、智能体、返回开头、跳到末尾、文本选择和插入换行。

## 9. 正文 AI 工具栏

以下按钮均位于正文上方。为避免消耗灵石或覆盖内容，本次仅记录，未执行生成。

## 17. 功能关系与工作流总结

该产品的推荐使用链路可以概括为：

1. 通过灵感火花、仿写或智能导入完成立项。
2. 在作品页确定标签、读者方向、文风、世界观、主角、力量体系和金手指。
3. 生成总纲，再从总纲拆分卷纲和章纲。
4. 在设定库维护角色、实体、关键事件和伏笔。
5. 按章生成、续写、优化、审稿、润色和重写正文。
6. 通过设定更新从新增正文中增量提取长期状态。
7. 使用小说全能助手读取作品资料，进行跨模块任务和 Diff 写入。
8. 使用历史版本和回收站恢复误操作。
9. 导出 TXT，或借助插件同步发布至番茄。
