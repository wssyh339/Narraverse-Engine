# 路线图

本路线图坚持本地优先。云协作、账号系统、支付和自动投稿不属于 1.x 目标。

## 1.0 稳定化

- 通过 Docker Compose 和本地开发命令实现可靠启动。
- 完成创作 Star 立项流程：候选卡片、正典预览、确认入库。
- 完成大纲 Swarm：总纲、动态卷纲、批量章纲预览。
- 完成章节写作工作流：canon context、质量门、修订和风格统一。
- 完成正典库：角色、实体、世界事实、图谱、伏笔、连续性问题和版本。
- 完成 Markdown/TXT/HTML/PDF/EPUB/Word 导出路径。
- 保持后端契约测试和前端路由/API 契约测试。

## 1.1 贡献者体验

- 增加多个类型的示例项目。
- 增强无 API Key demo 模式的稳定性。
- 完善 GitHub issue 模板和 PR 模板。
- 在 docs 中补充更多架构图。
- 加强 Prompt Catalog 和 workflow handoff 测试。

## 1.2 写作质量

- 增加更细的中文网文类型预设。
- 强化时间线、秘密、角色认知和伏笔回收检查。
- 支持按场景类型配置风格档案。
- 优化 AI 改写提案的 diff 视图。

## 1.3 扩展性

- 增加更多 OpenAI 兼容供应商配置示例。
- 可选本地模型适配器。
- 导出模板目录。
- Prompt Pack 导入/导出格式。

## 暂不计划

- 用户登录和托管账号。
- 云端团队协作。
- 支付或订阅系统。
- 自动发布到外部平台。
- 默认引入 Neo4j 或复杂向量数据库。
- 前端管理 LLM API Key。
