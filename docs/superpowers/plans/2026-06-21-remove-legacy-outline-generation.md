# 删除旧大纲生成流程

## 目标

彻底移除旧的两段式大纲生成入口与前端流程，只保留“回合制实时议事”作为大纲生成、确认与写入的唯一工作流。

## 执行范围

1. 后端删除旧路由、legacy facade、公开 service 方法和旧请求 schema。
2. 大纲议事提交不再复用旧 commit API，改为直接从已确认候选写入 Story Bible、Volumes、Chapters 与正典引用。
3. 前端删除旧大纲生成弹窗、推演图组件、旧请求构造器和 API 封装。
4. 测试改为验证旧入口不存在，并保留议事流覆盖。
5. 更新 AGENTS.md 与 README 中仍指向旧流程的活文档。

## 验证

- 后端针对性 pytest。
- 前端 contract/build 检查。
- `rg` 确认旧公开入口和旧组件引用清空。
