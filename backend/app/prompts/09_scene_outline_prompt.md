# 9. 场景细纲生成提示词

章节卡之后，可以继续拆成场景。
适合正式写正文前使用。

```text
请把以下章节卡拆解为可直接写作的场景细纲。

章节卡：

【粘贴章节卡】

要求：

1. 每个场景都必须有明确目标。
2. 每个场景都必须有冲突或信息变化。
3. 场景不能只是聊天，除非聊天中发生权力、关系、信息或情绪变化。
4. 每个场景结尾都要推动读者进入下一个场景。
5. 场景顺序必须形成递进，而不是平铺。
6. 请控制节奏，避免所有冲突都同样激烈。
7. 动作、对话、心理、环境描写要各有功能。

请输出：

场景总数：
本章节奏设计：

场景一：
场景地点：
出场人物：
场景开局状态：
场景目标：
显性冲突：
隐性冲突：
关键动作：
关键信息：
关键对话意图：
人物心理变化：
场景结尾变化：
连接下个场景的钩子：

场景二：
同上。

场景三：
同上。

最后请输出：
1. 本章情绪曲线
2. 本章信息释放顺序
3. 本章冲突升级顺序
4. 哪些地方需要留白
5. 哪些地方不能提前解释
```
