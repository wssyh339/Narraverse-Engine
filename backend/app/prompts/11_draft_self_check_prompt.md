# 11. 正文自检提示词

正文生成后，不要直接进入下一章。
先做一轮自检。

```text
你现在是小说结构编辑和文字编辑。

请审查下面这一章正文：

【粘贴正文】

对应章节卡：

【粘贴章节卡】

小说宪法：

【粘贴小说宪法】

请从以下角度审查：

一、结构层面
1. 本章是否完成章节功能？
2. 本章是否有明确开局状态和结尾状态？
3. 本章是否造成不可逆变化？
4. 主角是否主动做出选择？
5. 本章冲突是否来自核心矛盾，而不是随机事件？
6. 本章是否推进了人物、关系、伏笔或世界认知？

二、人物层面
1. 主角行为是否符合当前状态？
2. 配角行为是否符合自身欲望？
3. 是否有人物只是工具人？
4. 对话是否有潜台词？
5. 人物关系是否发生变化？

三、节奏层面
1. 开头是否太慢？
2. 中段是否松散？
3. 高潮是否有力度？
4. 结尾是否有下一章动力？
5. 是否有过多解释？

四、语言层面
1. 是否有总结腔？
2. 是否有重复表达？
3. 是否有过度形容？
4. 是否有不符合题材的现代词或套话？
5. 哪些段落可以压缩？
6. 哪些段落需要强化画面感？

请输出：

1. 本章最大优点
2. 本章最大问题
3. 必须修改的问题
4. 可以优化的问题
5. 具体修改建议
6. 建议重写的段落
7. 修改后的关键段落示范
8. 是否建议进入下一章
```
