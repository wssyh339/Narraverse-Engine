# 23. 上下文压缩提示词

AI 写长篇时，上下文会越来越长。
你需要定期把资料压缩成一个“下一轮可用上下文包”。

```text
请把以下资料压缩成适合下一轮继续创作的上下文包。

资料包括：

小说宪法：

【粘贴小说宪法】

已完成章节摘要：

【粘贴章节摘要】

当前叙事账本：

【粘贴叙事账本】

当前大纲：

【粘贴大纲】

要求：

1. 不要保留无关细节。
2. 必须保留影响后续剧情的事实。
3. 必须保留人物当前状态。
4. 必须保留关系变化。
5. 必须保留伏笔状态。
6. 必须保留世界规则。
7. 必须保留时间线。
8. 必须保留未解决矛盾。
9. 必须保留下一章写作所需信息。
10. 输出要清晰，便于我复制到新对话中继续使用。

请按以下格式输出：

一、小说宪法极简版
二、核心矛盾
三、主角当前状态
四、重要人物当前状态
五、重要关系当前状态
六、世界规则
七、已发生关键事件
八、未解决矛盾
九、伏笔账本
十、当前时间线
十一、当前卷目标
十二、接下来 5 章方向
十三、下一章必须承接的信息
十四、不能违背的既定事实
十五、禁止 AI 擅自改动的内容
```
