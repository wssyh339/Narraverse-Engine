# 2. 生成“小说宪法”的提示词

选定核心矛盾后，生成小说宪法。
这是后续所有大纲和正文都要遵守的最高规则。

```text
请根据以下核心矛盾系统，生成一份“长篇小说宪法”。

核心矛盾系统如下：

【粘贴核心矛盾系统】

请按照以下结构输出：

一、小说基本定位
1. 类型
2. 基调
3. 目标读者体验
4. 故事关键词
5. 类型承诺

二、核心叙事发动机
1. 主角最强欲望
2. 主角为什么必须追求它
3. 世界为什么阻止他
4. 核心矛盾一句话
5. 矛盾如何升级
6. 矛盾如何变形
7. 矛盾最终如何爆发

三、主角轨迹
1. 主角开篇状态
2. 主角表层目标
3. 主角深层需求
4. 主角最大缺陷
5. 主角最害怕面对的真相
6. 主角中期转折
7. 主角结尾状态
8. 主角从开篇到结尾的精神变化路径

四、世界规则
1. 世界最重要的运行逻辑
2. 权力如何分配
3. 资源如何分配
4. 普通人如何被规则限制
5. 主角如何被规则压迫
6. 哪些规则不能随意打破
7. 哪些规则可以在后期被揭示为更高层真相

五、主要人物功能
请设计：
1. 主角
2. 主要对手
3. 镜像人物
4. 诱惑者
5. 牺牲者
6. 怀疑者
7. 盟友
8. 背叛者
9. 见证者

每个人物都要说明：
- 欲望
- 恐惧
- 与主角的矛盾
- 对主题的作用
- 可能的关系变化

六、主题压力
1. 故事反复逼问的核心问题
2. 主角最初的错误答案
3. 反派给出的答案
4. 重要配角给出的答案
5. 主角最终可能抵达的答案

七、代价机制
1. 主角获得力量的代价
2. 主角赢得关系的代价
3. 主角追求真相的代价
4. 主角靠近权力的代价
5. 主角最终必须付出的最大代价

八、禁区
1. 哪些剧情方向不能走
2. 哪些人物行为不能违背
3. 哪些世界规则不能破坏
4. 哪些主题不能被削弱

九、长篇可持续性判断
请说明这个故事为什么能支撑长篇。
重点分析：
1. 矛盾是否能持续升级
2. 世界是否能逐层展开
3. 人物关系是否能持续变化
4. 主角是否有足够大的成长空间
5. 结局是否有必然性
```
