# 17. 世界规则管理提示词

适合设定复杂的玄幻、科幻、权谋、历史、悬疑小说。

```text
请根据当前世界规则表，检查设定一致性和剧情可用性。

小说宪法：

【粘贴小说宪法】

世界规则表：

【粘贴世界规则表】

当前剧情摘要：

【粘贴剧情摘要】

请完成：

一、规则一致性检查
1. 是否存在前后矛盾？
2. 是否有规则过于方便主角？
3. 是否有规则没有代价？
4. 是否有规则限制不清？
5. 是否有规则容易导致后期崩坏？

二、规则叙事价值检查
请判断每条重要规则：
- 是否能制造冲突
- 是否能限制主角
- 是否能制造代价
- 是否能推动世界展开
- 是否能服务主题

三、规则修正建议
对于问题规则，请给出：
- 原规则
- 问题
- 修改版本
- 修改后如何影响剧情
- 是否需要在正文中补充解释

四、后续可揭示的更高层规则
请设计 3 到 5 个可以在后期揭示的高层规则。
要求：
1. 不能推翻前文，只能重新解释前文。
2. 必须服务核心矛盾。
3. 揭示后要改变主角对世界的理解。
```
