# 4. 生成全书宏观大纲提示词

这个环节只生成大阶段，不要生成过细章节。

```text
请根据以下小说宪法，生成全书宏观大纲。

【粘贴小说宪法】

要求：

1. 不要写成事件流水账。
2. 全书分为 5 到 8 个大阶段。
3. 每个阶段都必须围绕核心矛盾升级。
4. 每个阶段结尾都必须造成不可逆变化。
5. 主角每个阶段都要获得某些东西，也失去某些东西。
6. 主角的精神状态必须逐步变化。
7. 世界必须逐层展开，而不是突然扩大。
8. 每个阶段都要有一个阶段性反派或阻力系统。
9. 每个阶段都要有主题压力。
10. 每个阶段都要为最终结局铺路。

请按以下格式输出：

阶段编号：
阶段名称：
阶段功能：
主角此阶段的表层目标：
主角此阶段的深层需求：
主要阻力：
阶段核心矛盾：
关键事件链：
主角获得：
主角失去：
人物关系变化：
世界认知变化：
主题压力：
阶段结尾的不可逆后果：
如何推动下一阶段：
潜在结构风险：
优化建议：

最后请输出：
1. 全书主角变化曲线
2. 全书核心矛盾升级曲线
3. 全书世界展开曲线
4. 全书主要伏笔布局
5. 全书结局的必然性说明
```
